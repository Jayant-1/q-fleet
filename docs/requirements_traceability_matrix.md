### 1. Document Overview
This Requirements Traceability Matrix provides complete bidirectional traceability from Smart India Hackathon Problem Statement 2 (SIH26138) and statutory international maritime standards down to source implementation modules, OpenAPI endpoints, UI components, automated verification test functions, evidential classifications, and delivery status.

### 2. Evidential Classification Taxonomy
Every metric, formula, and data source in Q-FLEET is categorized according to the official Claim-Evidence Framework:
- `[MEASURED DATA — EMSA MRV]`: 25,691 empirical annual vessel observations from official European Maritime Safety Agency reporting across 15,924 unique commercial vessels.
- `[EMPIRICAL ANNUAL PREDICTION]`: Machine learning annual emissions estimates with 95% conformal prediction intervals trained on EMSA 2022 data and evaluated on 2023 holdout.
- `[MODELED VOYAGE ESTIMATE]`: First-principles naval hydrodynamic proxy (Holtrop-Mennen calm-water resistance + ISO 15016 weather drag) for discrete single voyages.
- `[SYNTHETIC MATCHED-BUDGET BENCHMARK]`: Fair algorithmic comparison under identical computational budgets (1,050 evaluations, seed = 42).
- `[USER-SELECTED SCENARIO ASSUMPTION]`: Operational inputs configured by the evaluator (target speed, draft, weather severity, carbon tax).
- `[INDICATIVE REGULATORY ESTIMATE]`: Mathematical simulation proxy of IMO MEPC.354(78), EU ETS Directive 2023/959, and FuelEU Maritime Regulation (EU) 2023/1805.
